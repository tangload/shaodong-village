# 邵东村 · 文化 IP 与乡村振兴展示网站

一个介绍江苏宜兴湖㳇镇（湖父镇）邵东村的网站，内容涵盖**贡茶古道文化 IP、古琴大师成公亮与邵坞的故事、民间口述记忆、山水徒步玩水与乡村振兴实践**。

**本站是邵东村的公益宣传平台**：非商业、非盈利、免费向所有访客开放，不含商业广告、不做付费导流。建站目的只有三个——记录与传播村庄的文化与记忆、为村民乡贤和关心乡村的公众提供了解邵东村的窗口、服务乡村振兴公益宣传。驻村帮扶只是推动乡村振兴的其中一支力量。

线上地址：<https://tangload.github.io/shaodong-village/>

## 网站结构

首页 `index.html` 是门户，自上而下分为村情速览、贡茶历史、琴声山弯、民间记忆、好吃好玩、乡村振兴六个板块；每个板块都可点击进入对应二级页，二级页的「返回」按钮会回到首页对应板块。

| 页面 | 文件 | 作用 |
|---|---|---|
| 首页 | `index.html` | 门户概览，六大板块与统一导航 |
| 村情速览 | `cunqing.html` | 村庄概况、关键数据、村庄导览地图 |
| 贡茶历史 | `gongcha.html` | 廿三湾千年贡茶文脉、历史脉络、诗文与名物考证 |
| 廿三湾里的琴声 | `qinsheng.html` | 古琴大师成公亮与邵坞的相遇、小传与琴学记忆 |
| 民间记忆 | `minjian.html` | 口述历史正文：东岭岕的传说、奇人与风物 |
| 口述历史导览 | `minjiandaohang.html` | 民间记忆 / 口述历史各篇的索引总览 |
| 乡村振兴 | `zhenxing.html` | 当代篇章：媒体报道、人物、活动纪实与预告 |
| 廿三湾徒步 | `tubu.html` | 四条徒步线路、路线图与实用信息 |
| 溯溪玩水 | `xishui.html` | 永红涧亲子戏水攻略、玩水地图与安全须知 | 开发中
| 意见反馈 | `feedback.html` | 反馈问卷二维码与直链，可单独分享 |

## 本地预览

```bash
cd 邵东村网页
python3 -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123/
```

也可直接用浏览器打开 `index.html`（部分功能需通过本地服务器访问）。

## 发布与维护

站点托管在 GitHub Pages。当前仓库无远程连接，**内容更新由维护者手动上传至 GitHub 仓库**后生效；`.github/workflows/deploy.yml` 为预留配置，日常不依赖它。修改任何页面后，记得同步上传对应文件。

## 数据说明

本站内容据邵东村公开村情、村志资料、驻村工作记录及公开报道整理。涉及人口、资产、项目补助标准等数据，以主管部门正式文件与现场核实为准；民间传说与可考史实已尽量分别标注。镇名「湖㳇镇」亦作「湖父镇」：站内正文统一用「湖㳇镇」，检索相关字段（页面标题、描述摘要、结构化数据）保留「湖㳇镇（湖父镇）」双写，便于习惯写「湖父镇」的读者也能检索命中。
